[Example_SMC_LicensingInformation.json](https://github.com/ARENA2036/AAS-Examples/blob/main/etfa2026_modeling_of_software_and_services/Example_SMC_LicensingInformation.json)

A well-structured AAS JSON example for the _SubmodelElementCollection_ **LicensingInformation**, mapped to [ISO/IEC 19770-3](https://en.wikipedia.org/wiki/ISO/IEC_19770) concepts.
- Uses [SPDX identifier](https://spdx.org/licenses/) for _LicenseType_ (best practice).
- Contains realistic values for a commercial SaaS / industrial software license.
- Follows official AAS JSON structure.
- Ready to be embedded as a SubmodelElementCollection inside TechnicalData, SoftwareNameplate, or a Service AAS.
